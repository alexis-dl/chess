# Chess pieces

SVG chess pieces by Colin M.L. Burnett ("cburnett" set), from Wikimedia Commons
(files `Chess_[kqrbnp][ld]t45.svg`, e.g.
https://commons.wikimedia.org/wiki/File:Chess_klt45.svg).

They are triple-licensed by their author under GPLv2+, the BSD license and the
GFDL / CC BY-SA 3.0. Changes made here: files renamed (`white-king.svg`, ...)
and a `viewBox` added so that they scale.
